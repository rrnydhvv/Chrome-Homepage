# Chrome Homepage

A lightweight Chrome New Tab extension that loads a custom homepage quickly.

## Features
- Replaces the New Tab page with a custom HTML/JS experience.
- Fast load with minimal overhead.

## Files
- `manifest.json`: Extension manifest.
- `newtab.html`: New Tab UI markup.
- `newtab.js`: New Tab behavior.
- `fast-load.js`: Performance helpers.

## Install (unpacked)
1. Open Chrome and go to `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this folder.
